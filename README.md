# Random Joke Generator 😂

A fun and interactive joke generator that fetches jokes from multiple external APIs.

## Features

✨ **Multiple API Sources**
- JokeAPI (Various categories)
- Official Joke API (General jokes)
- Programming Jokes API

🎨 **Beautiful UI**
- Responsive design with Tailwind CSS
- Smooth animations
- Gradient backgrounds
- Mobile-friendly

🚀 **Functionality**
- Get random jokes on demand
- Copy jokes to clipboard
- Track number of jokes loaded
- Error handling with user-friendly messages
- Loading states with visual feedback

## How to Use

1. Open `index.html` in your web browser
2. Click "Get Another Joke" button
3. Read and enjoy the joke!
4. Use "Copy" button to copy the joke to clipboard
5. Repeat for more laughs!

## Technologies Used

- **React 18** - UI library
- **Tailwind CSS** - Styling
- **Babel** - JSX compilation
- **External APIs** - Joke sources

## API Sources

1. **JokeAPI** - https://v2.jokeapi.dev/
   - Supports multiple categories
   - Both single-line and two-part jokes

2. **Official Joke API** - https://official-joke-api.appspot.com/
   - General and programming jokes
   - Two-part jokes (setup + punchline)

3. **Programming Jokes** - https://official-joke-api.appspot.com/jokes/programming/
   - Tech and programming-related jokes
